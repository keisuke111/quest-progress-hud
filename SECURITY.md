# Security / セキュリティ

## Reporting a vulnerability / 脆弱性の報告

Use GitHub's [private vulnerability reporting](https://github.com/keisuke111/quest-progress-hud/security/advisories/new) for potential security vulnerabilities. Include the affected versions, reproduction steps, impact and a minimal example when possible. Do not include live credentials or private player/server data.

セキュリティ上の問題はGitHubの[非公開報告](https://github.com/keisuke111/quest-progress-hud/security/advisories/new)からお知らせください。対象バージョン・再現手順・影響と、可能なら最小の再現例を記載してください。有効な認証情報や非公開のプレイヤー・サーバー情報は含めないでください。

For ordinary HUD bugs or feature requests, use [Issues](https://github.com/keisuke111/quest-progress-hud/issues/new/choose).

通常のHUD不具合や機能要望は[Issues](https://github.com/keisuke111/quest-progress-hud/issues/new/choose)を使ってください。

## Maintenance scope / 対応範囲

This is an initial beta. Reports concerning the latest published beta and the environment documented in the README are the current focus. Older versions and other Minecraft versions/loaders do not have a promised security-maintenance period. Compatibility claims and dependency declarations do not guarantee that third-party software is free of vulnerabilities.

初回Betaのため、最新の公開BetaとREADME記載の環境を中心に報告を確認します。旧版や他のMinecraftバージョン・ローダーに対する保守期間は約束していません。対応環境や依存関係の記載は、外部ソフトウェアに脆弱性がないことを保証するものではありません。
