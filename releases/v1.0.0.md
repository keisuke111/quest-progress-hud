## Quest Progress HUD 1.0.0

The first stable release, following continued stable use of v0.0.10 reported by the author in All the Mods 10 v8.2.

### Included features

- A compact HUD with completed / total team quest counts, completion percentage and a progress bar.
- All-quest or selected-chapter progress, refreshed once per second while visible.
- Live layout editing over the game view: drag to position, preview size/background opacity, Save to apply, or Cancel/Escape to discard.
- An optional visibility toggle key, unassigned by default.
- Saved visibility, position, size, opacity and chapter settings, with English/Japanese configuration labels and help.

### Changes from v0.0.10

- Promote the tested feature set to 1.0.0; no gameplay code or translation changes.
- Refresh release documentation, download/support links and security maintenance wording.
- Include the repository license in the jar, and verify the packaged version and language resources during CI.

### Environment and upgrade

Minecraft **1.21.1**, Java **21**, NeoForge **21.1.251+** within Minecraft 1.21.1, and **FTB Quests (NeoForge)** with its dependencies are required. Install this HUD on the **client**.

The confirmed gameplay environment is **ATM10 v8.2 / NeoForge 21.1.251 / FTB Quests 2101.1.36**. ATM10 v8.5 and other modpacks are not confirmed by this release. Any required v8.5 compatibility fix will be handled separately, intended for 1.0.1.

Close the game, remove the older Quest Progress HUD jar, and install **quest-progress-hud-1.0.0.jar** in the instance's `mods` folder. Existing config and key bindings from v0.0.10 remain compatible; no reset is required.

### Counting and limitations

The HUD uses the currently synced **team's** completion data. **All quests** remains the default, including hidden, optional, repeatable and internal quests. Selecting a chapter limits both completed and total to that same chapter; no other filtering is applied. Repeatable quests count by current completion state, not repeat count. Empty scopes show **0 / 0 (0.0%)**.

Chapter selection is stored per instance. If its saved ID is absent in another world, choose another chapter or All quests. Broader multiplayer/team transitions and other environments still need in-game verification. Stable status does not mean all third-party dependency alerts have been resolved; see the repository's security documentation.
