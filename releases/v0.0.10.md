## Quest Progress HUD v0.0.10 — Beta

### Changes

- Edit the HUD directly over the game view: drag to reposition, preview size and background opacity, then Save. Cancel/Escape discards changes; Reset previews the default layout.
- Assign an optional **Toggle quest HUD** key in **Options → Controls → Key Binds → Quest Progress HUD**. It starts unassigned and saves your visibility preference.
- Choose **All quests** or one chapter from **Mods → Quest Progress HUD → Config → Select chapter**. Missing saved chapters show **Chapter unavailable** until you choose another scope.

The compact HUD, one-second refresh and existing settings remain compatible. **All quests** remains the default, including hidden, optional, repeatable and internal quests. Both completed and total counts use the selected scope and the currently synced team's progress.

### Environment and installation

Client-side, Java 21, Minecraft **1.21.1**, NeoForge **21.1.251+** within that Minecraft version. Built and tested with FTB Quests **2101.1.36** in **ATM10 v8.2**. FTB Quests and its dependencies must already be installed. Other Minecraft versions, loaders and modpacks are not verified.

Close the game, remove the previous Quest Progress HUD jar, and place **quest-progress-hud-0.0.10.jar** in the instance's `mods` folder. Existing settings are retained. Configuration labels/help are available in English and Japanese.

### Validation

Automated feature checks passed and the author confirmed layout editing, key toggling and chapter selection using the combined development build. Other modpacks and broader multiplayer/team transitions still need testing.
